判定
----
`tool_execution_update.partialResult` 是「截至当前的累计快照」，不是增量。
宿主投影层原样传递该字段（kernel/projection.py::_tool_execution_update），
因此**替换显示的责任在前端**。

修复与回归
----------
* web/modules/run-stream.mjs::updateTool —— 由 `item.output + payload.output`
  改为 `typeof payload.output === 'string' ? payload.output : item.output`；
  模块头与函数内注释均写明累计快照语义与出处。
* web/modules/run-view.mjs —— 工具状态文案集中在 `TOOL_STATE_LABELS`
  （执行中/完成/失败/已取消/已中断）；`styles.css` 为 interrupted/cancelled 补配色。
* web/modules/run-stream.mjs::finishRun —— 失败/取消时仍未结束的工具不再标
  `done`：finished→done、failed→interrupted、cancelled→cancelled；
  已拿到自身 `tool_finished` 的工具保持原状态。
* Node 回归（tests/web/run-stream.test.mjs，node --test tests/web/*.test.mjs）：
    ✔ cumulative tool snapshots replace the display instead of duplicating prefixes
      （复刻本 run 的 0 → 53 → 495 形状，断言等价于替换、短于拼接、前缀不重复）
    ✔ a failed or cancelled run never leaves a running tool looking done
      （run_failed→interrupted、run_cancelled→cancelled；已终态工具不受影响）
    ✔ tool cards track streaming output and final status（改为累计快照形状）
  结果: 14 项通过 / 0 失败（Python 全套 97 项另行复验）。
