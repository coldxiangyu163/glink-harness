⑧ 评审修复：`/` 命令门禁（GLINK-SUB-02 第 1 轮 BLOCKER）
----------------------------------------------------------
背景: 载入 pi-subagents 后，客户端可控的 prompt 如果以 `/` 开头，pi 会先执行扩展命令
（docs/rpc-commands.md:31），`/run --bg`、`/subagents-detach` 等因此绕过 tool_call 守卫；
inproc 面会留下不随 run 取消/超时收口的孤儿进程。
修复: 宿主在准入层加门禁（kernel/runner.py::RunManager.start → prompt_names_unsupported_command，
命令名单从 kernel/agent_env.py::prompt_template_names(config.agent_config_dir) 推导；
web_routes.py 把 UnsupportedCommand 映射为 HTTP 400 unsupported_command）。
拒绝发生在凭据解析、父会话读取、run 目录创建、执行面拉起之前；追问与三个执行面同一条判定。
