# ACP 类客户端-代理协议对宿主接多 harness 的价值

- **消除 N×M 适配**：无标准时，每个宿主与每个 harness 的组合都要定制集成；实现 ACP 后，宿主一次实现即可接入整个兼容代理生态（[ACP 官方介绍](https://agentclientprotocol.com/overview/introduction)，已核实其明确陈述此点）。

# ACP 对宿主接多 harness 的价值

- **解耦、消除 N×M 集成成本**：ACP（Agent Client Protocol）标准化了客户端（编辑器/宿主）与编码代理之间的通信。没有它，每接一个新 harness 都要定制对接；接入 ACP 后，任何兼容 ACP 的代理都能即插即用，类似 LSP 之于语言工具（[ACP 官方介绍](https://agentclientprotocol.com/overview/introduction)）。
