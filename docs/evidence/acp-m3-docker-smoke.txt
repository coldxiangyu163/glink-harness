# 容器隔离对 AI 编程 agent 运行安全的价值

- **限制爆炸半径**：把 agent 生成的代码与第三方组件放进加固容器/沙箱运行，并限制文件系统、资源与生命周期，模型即便被提示注入或产生越权行为，也只能在这个短生命周期的受限环境里活动，无法直接触碰宿主文件、凭据与后端系统。[来源 1]
- **文件系统与网络两道边界缺一不可**：只做文件系统隔离时，被攻陷的 agent 仍可能外传 SSH 密钥等敏感文件；只做网络隔离时，它可能先篡改系统资源以换取网络出口。两层同时生效，才能既保留较高自主性，又降低数据外泄与植入持久化后门的风险。[来源 2]
