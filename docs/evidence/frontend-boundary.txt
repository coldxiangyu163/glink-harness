前端报告层剥离证据 / front-end report-layer strip evidence
==========================================================
日期: 2026-09-22（第七次审计返工）
审计复现对象: 审计意见「前端仍保留完整的 Glink 特有报告渲染层：web/modules/markdown.mjs
              与 FrontierAgent 对应文件逐字相同，包含 chart/flow、artifact、引用和事实
              标签等 852 行逻辑及相关 CSS。这违反『剥离 Glink 特有依赖』和『不实现图表
              渲染』等边界，且与验收记录『未做图表』矛盾。」

修复方式：重写为项目自有的最小 Markdown 渲染器，删除 Glink 报告层
------------------------------------------------------------------
* `web/modules/markdown.mjs` 852 → 256 行。只保留标题、段落、强调、链接、图片、
  代码围栏、列表、引用、分隔线与管道表格；删除 chart/flow 渲染、artifact 解析、
  引用标注（citation）、事实标签（qualifier/fact label）、LaTeX、报告图表降级等
  全部 Glink 报告层逻辑。
* `web/modules/i18n.mjs` 删除（35 行）：前端不再带产品文案字典。
* `web/modules/ui.mjs` 130 → 36 行：只留 `escapeHtml` 与 `safeUrl`。
* `web/styles.css` 957 → 454 行：移除 `.citation`、`.citation-link`、`.qualifier-badge`、
  `.report-table-wrap`、`.report-chart*`、`.report-source-entry`、`@keyframes source-flash`
  等报告层样式；补充纯 prose（`.pi-text` / `.preview-body`）与 `.md-table-wrap` 表格样式。
* 图表围栏按普通代码块渲染：```chart 输出 `<pre><code class="language-chart">`，
  不再有任何图表降级/图元生成路径。
