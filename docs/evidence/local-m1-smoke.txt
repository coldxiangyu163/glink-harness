# pi 内核接入：关键约束与三个高频陷阱

## 结论摘要

pi 应被当作**独立子进程内核**接入，而不是 Python 库：宿主通过 `pi --mode rpc` 启动进程，
并以 stdin/stdout 上的 JSONL 协议通信。接入正确性的核心在于四点：运行期生成隔离配置、
严格按 LF 拆帧、按请求 `id` 关联响应且不阻塞事件读取线程，以及用真正的"落定"状态
而非中间事件判断 run 完成。
