两次失败与原因（都不是网络问题，已写进 Dockerfile 注释）:
  1) CMD ["sh","-c","dsh --version && codex-acp --version"]：E2B 构建把 CMD 数组用空格拼成
     一行再交给 shell（日志 "Running start command: sh -c dsh --version && codex-acp --version"），
     `sh -c dsh --version` 把 --version 当 $0，dsh 报 "--profile <name> is required"，构建失败。
     修复：CMD 指向镜像内脚本 acp-self-check。
  2) RUN printf '%s\n' …：E2B 构建解析把 Dockerfile 文本里的 \n 吃成 n（日志里的 RUN 命令即为
     `printf '%sn' …`），脚本没有换行，execve 报 "cannot execute: required file not found"。
     修复：改为逐行 echo 生成脚本，不出现转义符。
