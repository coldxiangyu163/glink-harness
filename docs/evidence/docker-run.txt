镜像
----
名称/标签   pi-glink-worker:latest
体积        1.09 GB
基础镜像    node:24-bookworm-slim
镜像内 pi   @earendil-works/pi-coding-agent@0.86.1（容器内 `pi --version` 实测输出 0.86.1）

构建命令（本机网络环境，基础源覆盖为可选项；仓库默认用官方源）:
  docker build -t pi-glink-worker:latest -f docker/Dockerfile.worker \
    --build-arg DEBIAN_MIRROR=mirrors.aliyun.com \
    --build-arg NPM_REGISTRY=https://registry.npmmirror.com .

真机首次构建耗时约 5 分钟（apt + npm 安装 pi）。默认官方源在本机网络下会卡在
`Ign: deb.debian.org ... InRelease`，因此 Dockerfile 暴露了 DEBIAN_MIRROR / NPM_REGISTRY
两个 build arg；仓库默认值仍是官方源。

边界证据
--------
* 镜像自包含：`docker run --rm pi-glink-worker:latest pi --version` 在无任何挂载的
  情况下输出 0.86.1，说明容器不依赖宿主安装的 Node / pi。
* 宿主只提供数据通道：工作区挂到 /workspace、运行期配置挂到 /config、会话挂到
  /sessions；凭据用 `-e OPENAI_API_KEY` 按变量名转发（值不出现在 argv）。
* 停止语义：run 结束或取消后宿主执行 `docker rm -f <container>`（--rm 已覆盖正常路径）。

tests/test_kernel_docker_env.py（6 项）：挂载边界、凭据不落 argv、daemon 缺失时明确失败、
