会话文件路径映射（返工点）
--------------------------
* 容器内 pi 报告 `/sessions/<file>.jsonl`；宿主把该路径映射回 `<data>/sessions/<file>.jsonl`
  后再做收尾脱敏（`kernel/docker_env.py::host_session_path`）。
* 映射是纯词法的：相对路径、前缀伪装（`/sessions-other`）与 `..` 穿越一律拒绝。
* `_sanitize_session_file` 找不到文件时显式告警，不再静默返回。

边界证据
--------
* 镜像自包含：`docker run --rm pi-glink-worker:latest pi --version` 在无任何挂载的
  情况下输出 0.86.1，说明容器不依赖宿主安装的 Node / pi。
* Node 版本固定：基础镜像 pin 到 `node:24.21.0-bookworm-slim`，容器内实测 v24.21.0；
  Docker 与 E2B 使用同一精确 tag。
* 宿主只提供数据通道：工作区挂到 /workspace、运行期配置挂到 /config（含 auth.json 凭据）、
  会话挂到 /sessions；模型凭据不经环境变量、不进 argv、不写进镜像。
* 停止语义：run 结束或取消后宿主执行 `docker rm -f <container>`（--rm 已覆盖正常路径）。
