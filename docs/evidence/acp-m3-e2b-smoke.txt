# 云沙箱隔离对 AI 编程 agent 运行安全的价值

- **限制爆炸半径**：agent 会执行自己生成的代码和第三方脚本；云沙箱把执行放进加固的容器/沙箱，限定文件系统、资源配额与生命周期，代码行为异常时也波及不到宿主与生产数据。
- **收敛网络与能力边界**：沙箱收紧出网（egress 白名单）、只暴露窄接口而非通用 shell/网络权限，可降低数据外泄与横向移动风险，并使高危操作可审批、可审计。

来源：[Microsoft Learn — 6. Runtime Isolation and Sandboxing](https://learn.microsoft.com/en-us/security/zero-trust/catalog-ai-defense-capabilities/runtime-isolation-sandboxing)（2026-08-01 更新，已打开核验）

一句话总结：云沙箱隔离把 AI 编程 agent 的代码执行关进受限、短生命周期且出网受控的环境，用可审计的边界换取「即使 agent 出错或被诱导也难以伤及宿主与生产系统」的安全下限。
