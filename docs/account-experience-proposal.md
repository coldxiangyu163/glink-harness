# 多租户账号与前端入口（待批准的设计提案）

**状态：仅设计，未实现账号注册、登录或会话存储。** 当前 `PI_GLINK_TENANCY=multitenant` 只接受认证网关注入的签名身份断言；默认 `local` 模式没有账号。不能只加两张表单就声称有多租户认证，也不能让浏览器自行提交 `tenantId` 冒充身份。

## 选择与范围

建议首发**邀请制注册 + 站内登录**，与现有网关模式并存但互斥启用：`local` 保留单用户调试；多租户部署从 `gateway`（现有签名断言）或 `accounts`（新增站内会话）中选一项。无开放式自助创建租户、无邮箱发送、无单用户跨组织切换；这些功能未决定前不画看似可用的控件。

```
认证网关断言 ─┐
               ├─► 服务端 TenantContext ─► 原 RunManager/RunStore owner 校验
站内会话 cookie ┘
```

站内账号以仓库外 SQLite（WAL）管理用户、租户、邀请和会话；不借此重写现有 run/events 文件存储。首位租户管理员由操作员通过离线命令创建邀请；管理员登录后可生成限定租户、邮箱、角色且一次有效的邀请，安全渠道自行交付。用户在邀请注册页设置密码，注册成功后登录；未经邀请不能创建账号或租户。注册**不**自动获得模型凭据，管理员仍按现有 `0600` 租户配置提供模型 key，缺失时工作台提示“模型服务尚未配置”，不能回退到其他租户的 key。

服务端只在鉴权通过后生成 `TenantContext`：本地模式不生成；网关模式沿用 HMAC 验签；站内模式校验不可预测、只存哈希的会话令牌，并从服务端账号记录读取 `tenantId/userId/role/status`。密码用随机盐的内存困难哈希、恒定时间比较；cookie 使用 `HttpOnly`、`Secure`（仅经 HTTPS 网关）、`SameSite`，登录/注册限速，状态变更必须防 CSRF。停用账号/租户立即使会话失效，SSE 需在会话失效时断开，已有 run 的取消、资源清理仍走原归属规则。账号库、run 历史、模型凭据不共享迁移；旧无 owner 的历史继续只在 local 模式可见。

## 前端信息架构（以百鉴 UI 库为准）

参照 `/Users/coldxiangyu/work/BR/glink-ui-library` 的 `src/styles/globals.css`、`src/components/{input,button,field}.tsx`、`src/pages/agent-assistant-demo/demo-sidebar.tsx` 与《百鉴 UI Design Specification.md》§2.2、§3.3、§4.3。本站仍是无打包的静态 ESM：逐值映射现有 `web/styles.css` token，不引入 React、Tailwind 或第二套色板。主操作为近黑胶囊按钮，单行输入按库规范 36px/全圆角，聚焦为 1px 近黑描边，错误在字段旁显示；键盘焦点与触屏目标遵循现有无障碍合同。

1. **未登录 `/login`**：保留品牌标识与浅色页面材质；主区单列，宽度约 400px，标题“登录研究工作台”，邮箱、密码、登录按钮；下方文字链接“收到邀请？创建账号”。登录失败在对应字段或表单内说明原因，不泄漏邮箱是否存在；网络失败与密码错误可重试且不清空邮箱。无营销英雄区或假的组织切换器。
2. **邀请注册 `/register?invite=…`**：未带有效邀请时显示“需要邀请才能创建账号”并给返回登录入口；有效邀请显示组织名、受邀邮箱（只读）、姓名、密码和确认密码；密码要求与错误规则就地说明。提交成功转登录，不在 URL 或本地存储留下邀请码，不显示第三方登录按钮。
3. **工作台**：启动时先请求 `GET /api/me`，收到 `200` 才揭示研究历史；`401` 跳登录，绝不先闪现上一个身份的历史。左侧导航底部参照库 Demo 的 28px 首字母头像，显示当前**真实**组织名、姓名及账号菜单“账号信息 / 退出登录”。窄侧栏保留可访问名与 tooltip。组织名来自服务端，不从运行记录、URL 或浏览器存储猜。
4. **会话失效**：读面 `401` 时关闭当前 SSE、清除屏幕上的研究与报告内容、引导重新登录；重新登录后重新读取有权访问的列表。退出登录废止服务器会话并清空前端当前身份数据，不能只隐藏 UI。

## 接口、兼容与验收

建议新增 `GET /api/me`、`POST /api/auth/login|register|logout`、管理员发邀请接口；`GET /api/me` 只回当前用户、组织的展示字段与权限，不回签名密钥、模型凭据或其他用户。所有 run/list/detail/SSE/report/stop/follow-up 继续使用现有 owner 校验，不从新页面另造授权路径。默认 `local` 行为不变；`gateway` 模式现有断言也能提供 `/api/me` 用于身份展示，登录/注册入口应由网关提供或隐藏，不展示无后端的站内表单。

隔离验收：两租户注册与登录、跨租户列表/详情/报告/SSE/取消/follow-up 拒绝；受邀邮箱与组织绑定、重复/过期/伪造邀请码、弱密码、登录限速、会话过期/停用/退出、CSRF、浏览器刷新与身份切换无历史串显；独立 fake pi/临时数据库/随机 loopback 端口下实际浏览器走完整流程。真实网关、邮件交付、Docker/E2B live、已有用户数据迁移与部署另验收。本提案获批前不修改真实配置、数据、服务或生产凭据。
